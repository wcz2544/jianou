# 见瓯｜建瓯家乡宣传网页

这是根据《建瓯家乡宣传网页策划与内容资料》制作的第一版静态网页，可直接部署到 GitHub Pages。

## 文件说明

```text
├─ index.html                 网页结构和文字
├─ css/style.css             颜色、排版、手机适配和视觉效果
├─ js/app.js                 主题卡片数据、筛选、菜单和动画
├─ assets/favicon.svg        浏览器标签小图标
└─ 素材替换说明.md            后续换照片、改文字的方法
```

## 当前版本边界

- 已完成：首页、八主题筛选、味道专题、三条策划路线、实用提示、手机端适配。
- 暂未放网络照片，因为原策划明确说明照片和视频的发布授权尚未确认。
- 店铺地址、价格、开放时间、交通和当期活动，应在实地或官方核验后再发布。
- 页面中的路线是内容策划方向，不是已经核验的导航路线。

## 技术特点

- 原生 HTML、CSS、JavaScript，无需安装依赖。
- 支持 GitHub Pages 免费静态部署。
- 内容卡片集中写在 `js/app.js`，便于继续扩展和迁移。
- 支持手机、平板、电脑及“减少动画”系统设置。
